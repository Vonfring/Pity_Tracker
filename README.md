# Genshin Pity Tracker

Hitung pity Genshin Impact otomatis dari riwayat wish.

Ini **hanya** wish tracker — bukan companion app. Tidak ada ascension calculator, todo list, atau database karakter.


## Catatan

- **Riwayat cuma 1 tahun.** Sejak versi 4.5, game hanya menyimpan riwayat wish setahun terakhir. Pull yang lebih lama tidak bisa ditarik lagi oleh tool mana pun — sesekali export datamu.
- **Deteksi 50/50 adalah heuristik.** Aplikasi ini tidak punya database banner historis, jadi status guaranteed ditebak dari daftar standard pool. Bisa meleset, karena itu ada tombol koreksi manual di tiap kartu.
- **Epitomized Path belum ada.** Fase 2.

Tidak berafiliasi dengan HoYoverse.
